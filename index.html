VellumFE Assets

A federated asset repository for VellumFE, installable in-app with the .jinx asset manager.

Each category below publishes a manifest.json over the Jinx protocol; repos.json indexes them all. In VellumFE, just run .jinx list and .jinx install <name>.

Contribute: submit dolls, frames, backgrounds, icon sheets, compass art, or status icons through a guided submission form — no git required. Skins and layouts go in by pull request.

Built and published automatically by GitHub Actions on every push. This page reads repos.json and the live manifests, so it is always current.
