VellumFE Assets

A federated asset repository for VellumFE, installable in-app with the .jinx asset manager.

These are served over the Jinx protocol: each category below publishes a manifest.json that VellumFE reads to list and install assets. In VellumFE, just run .jinx list and .jinx install <name>.

Icon maps

Hotbar icon sheets. Install one and it drops into your shared icon pool (~/.vellum-fe/global/icons/) next to the rest.

Injury dolls

Paper-doll base images. A skin's [injury_doll] can point at an installed doll.

Skins

Full GUI graphics themes (backgrounds, borders, icons), installed as a skin folder you activate with .setskin.

Layouts

Shareable window arrangements and UI packs exported with .uiexport.

Want to contribute a skin, icon set, or layout? See SETUP.md for the folder layout and how the manifests are generated.

Built and published automatically by GitHub Actions on every push.
